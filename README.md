# 🎓 AI-Based Facial Recognition Attendance System

An intelligent, real-time facial recognition attendance system built using **Python**, **OpenCV**, and **Streamlit**.

## ✨ Features
- 📹 **Real-Time Attendance Verification:** Capture photo via webcam and verify profile.
- ➕ **Student Registration:** Add new student profiles seamlessly.
- 📊 **Logs & Analytics:** View real-time attendance history and status metrics.
- 📥 **Export Reports:** Download attendance logs directly as CSV files.

## 🚀 Tech Stack
- **Frontend / Dashboard:** Streamlit
- **Computer Vision:** OpenCV
- **Data Processing:** Pandas, NumPy
- **Language:** Python 3.x
